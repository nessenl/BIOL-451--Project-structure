Course Title: Image Based Data Analysis and Visualization of Benthos
Project Description: The student will be provided a research experience working to learn image analysis methods for benthic ecology. The student will interact with NOAA biologists at Hollings Marine Lab. The focus of work is a large dataset of coral images recently collected by NOAA. The student will learn coral biology and ecology, benthic survey methods, image data and metadata; batch processing, scale and measurement, data analysis and visualization techniques. The primary products of this work will be a poster presentation, some basic python code, and enhanced image datasets.
